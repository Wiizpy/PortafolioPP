## Subsecciones

En esta práctica se abordaron tres temas principales:

* Markdown: Sintaxis básica, estructura de documentos y formato de texto
* Git y GitHub: Uso de repositorios, control de versiones y subida de archivos a la nube
* Hugo y GitHub Actions: Generación de páginas estáticas y automatización de despliegue en GitHub Pages

## Descripcion de la practica

La práctica tuvo como objetivo introducir el uso de repositorios y herramientas modernas utilizadas en el desarrollo de software. Se trabajó con Markdown para la creación de documentos estructurados, Git como sistema de control de versiones y GitHub como plataforma de alojamiento de repositorios

Posteriormente, se integraron estos conocimientos para generar una página estática utilizando Hugo, y se automatizó su publicación mediante GitHub Actions, permitiendo desplegar el sitio en GitHub Pages

## Dessarollo de la practica

Durante la primera sesión se investigó qué es Markdown, su utilidad y su sintaxis. Se elaboró un documento aplicando encabezados, listas, negritas, cursivas y otras herramientas de formato

En la segunda sesión se trabajó con Git y GitHub. Se aprendió a:

* Crear un repositorio
* Inicializar Git
* Agregar archivos (git add)
* Confirmar cambios (git commit)
* Subir información (git push)

Además, se comprendió la importancia del control de versiones y del trabajo colaborativo

En la tercera sesión se utilizó Hugo para generar una página estática. Se configuró la estructura del sitio, se añadieron contenidos y se vinculó el repositorio con GitHub Actions para automatizar la publicación en GitHub Pages

Finalmente, se obtuvo un sitio web (HUGO) funcional alojado en la nube

## Conclusiones

Esta práctica permitió comprender la importancia de utilizar repositorios y herramientas de control de versiones en proyectos académicos y profesionales. Se aprendió que Markdown facilita la creación de documentación clara y organizada, mientras que Git y GitHub permiten gestionar cambios de manera segura, también se observó cómo Hugo y GitHub Actions simplifican la creación y despliegue de páginas estáticas, automatizando procesos que de otra forma serían manuales
